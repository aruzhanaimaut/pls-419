# Көпір: an AI answer for Kazakhstan's kandas children

Final project for PLS 419 (2026). A public website about kandas (ethnic Kazakh returnee) children in Kazakhstan's schools: the problem, the data and its silences, the state of research, and a proposed AI reading tutor with its full environmental, economic, labour, governance and data-ethics bill.

Live site: https://aruzhanaimaut.github.io/pls-419/

Files: `index.html` (content), `style.css` (design), `app.js` (charts, calculator, interactions), `fonts/` (self-hosted Literata, Golos Text and Noto Naskh Arabic, all SIL Open Font License).
